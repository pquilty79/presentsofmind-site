# Presents of Mind

Official product information, support, and privacy website for Presents of Mind, by Patrick Quilty.

Presents of Mind is an iPhone and iPad gift-riddle adventure app. Planned US App Store price: **$0.99**, with no in-app purchases or advertising.

## Publish with GitHub Pages

In **Settings → Pages**, select **Deploy from a branch**, then **main** and **/docs**, and save.

Site: https://pquilty79.github.io/presentsofmind-site/

- [Support](https://pquilty79.github.io/presentsofmind-site/support.html)
- [Privacy policy](https://pquilty79.github.io/presentsofmind-site/privacy.html)

This repository contains only the static public website. The native app source is maintained separately.
